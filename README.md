# SkillBridge – Student Skills & Career Development System
## 1. Project Overview

SkillBridge is a MySQL-based Student Skills and Career Development System.

- Manages student information and skill details.
- Maintains student skill proficiency levels.
- Stores company and career opportunity information.
- Manages job and internship applications.
- Maintains student certification records.
- Helps retrieve and analyse career-related information using SQL queries.

## 2. Project Objectives

1. To maintain student information systematically.
2. To manage student skills and proficiency levels.
3. To store company information.
4. To manage job and internship opportunities.
5. To track student applications.
6. To maintain student certification details.
7. To establish relationships between database tables.
8. To retrieve useful information using SQL queries.

## 3. Technologies Used

## 4. Database Design

# The SkillBridge database consists of the following tables:

# S.No.| Table Name| Description
1| Students| Stores student details.
2| Skills| Stores available skills.
3| Student_Skills| Connects students with their skills.
4| Companies| Stores company information.
5| Opportunities| Stores job and internship details.
6| Applications| Stores student application details.
7| Certifications| Stores student certification details.
8| Application_Status_History| Tracks application status changes.
